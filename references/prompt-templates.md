# 高密度叙事装饰插画与有限动画提示词模板

## 使用规则

- Skill 被调用即代表用户已选择本视觉体系；不得询问是否采用该画风，也不得把它列为待确认项
- 低/中高饱和、清晰线条/柔和材质由上下文判断；只有内容事实或输出规格缺失到无法执行时追问
- 开始即读取 style-guide.md；所有生成先完成 Asset Gate 与 Prompt Conflict Gate，实际传入固定模块 assets，并把每张图的可观察继承规则展开进最终提示词
- 只输出当前任务需要的路径
- 用户或上游已有故事时忠实适配；只有输入停留在主题时才补足最低叙事结构
- 先写主体、故事、环境和构图，再写可观察的视觉规则；不要依赖风格名称代替技术描述
- 根据任务选择必要 assets，不无差别引用六张图
- 输出规格只继承用户或上游明确值
- 所有路径明确排除丝巾、方巾、面料、服饰印花、纺织品和商品设计误解

## 故事输入判断模板

```yaml
story_input_level: "Level 0 / Level 1 / Level 2 / Level 3"
source_facts:
  must_preserve: "用户或上游已明确的角色、关系、时代、事件、结局与其他剧情事实"
  may_complete: "允许补足但不得覆盖原设定的部分"
  must_not_invent: "不得新增的角色、品牌、事件、反转或结局"
```

## 最小故事单元

仅在 Level 0 或 Level 1 信息不足时补足：

```yaml
minimal_story:
  initial_state: "人物、道具、环境与信息的初始状态"
  immediate_intent: "人物此刻可拍摄的具体目标"
  trigger: "引发注意或行动变化的事件"
  visible_action: "观众能看到的一个核心行动"
  visible_change: "人物、道具、环境、信息或情绪的局部变化"
  exit_state: "结束时的新状态"
```

## 单帧故事模板

```yaml
single_frame_story:
  before: "画面发生前一刻"
  visible_now: "当前画面中可直接看见的事件"
  implied_after: "画面暗示的下一步"
```

最终图像提示词以 `visible_now` 为主；`before` 和 `implied_after` 只用于增强叙事，不强制全部画入。

```yaml
  key_prop_function: "目标物 / 触发物 / 线索物 / 关系物 / 状态物 / 结果物"
```

## 镜头故事功能

每个镜头至少选择一个：

```text
establish / clue / action / reaction / reveal / consequence / transition / resolution
```

相邻镜头必须产生新信息、新动作、新反应、新后果、新空间关系或新情绪。若只有景别变化，合并或删除。

## 核心正向风格块

```text
高密度叙事性二维装饰插画：叙事关系密度高而视觉噪声低，角色行动、关键道具、线索与环境响应形成多层可读关系；细节成组分布，留白区完整。以精密、清晰、流畅、闭合的数字轮廓构成骨架，外轮廓明确，内部结构线更少更轻，远景线条适度减弱；用大而完整、边界干净的离散色面与固有色平涂组织空间，色块内部无刷痕、纸纹或颗粒；仅在具有叙事、身份或材质意义的区域配置局部复杂纹样。构图具有秩序感、形式化、规整和编辑设计感，主体与关键事件优先于环境碎节；空间通过开口、结构边界、遮挡和色块层级建立，并以中长焦或偏长焦压缩透视，减少近大远小、强消失点和广角扩张。任意暂停帧均可作为完整二维插画独立成立。
```

## 局部材质块

只在内容需要时选择：

```text
以平涂、闭合线条和固有色为主导；局部材质只作为从属提示。单一对象默认只允许一种主要材质方法、一个局部强调区和一类受控效果。机械、金属、珠宝、玻璃、灯具等强材质题材自动进入严格平面化模式：删除重复的高光、珠光、辉光、反射、透明和表面纹理描述，仅用一个扁平小色块暗示材质。不得进行大面积渐变、摄影式落影或三维塑形。
```

## 通用负面块

```text
非丝巾、非方巾、非面料、非服装印花、非纺织品、非产品设计。保持闭合数字线、大而完整的平涂色面、成组细节、完整呼吸区、中长焦压缩空间。角色排除超大高光眼、尖下巴、束状动漫发片、夸张睫毛、腮红光斑、赛璐璐脸影；场景排除水彩/水粉/油画笔触、纸纹颗粒、粉彩晕染、碎笔触植被、发光空气透视、日系动画背景式光斑、广角扩张；道具排除商品摄影、棚拍白底、写实投影、镜面反射、塑料高光、三维产品渲染和孤立陈列。避免粗重漫画描边、抖线、色块不均、大面积写实渐变、三维塑形、纹样游移、道具形变、透视重建、镜头晃动、身份漂移、重复人物、无关文字与 UI。
```

## 风格兼容转译模板

在写最终提示词前完成：

```yaml
prompt_translation:
  must_show:
    - "决定身份、状态、动作与故事识别度的事实"
  symbolized_structure:
    - source: "必须存在但容易引发细节堆砌的结构事实"
      rewrite: "用扁平几何、闭合色块和少量线组表示；不展开厚度、装配、纹理或反光"
  removed_or_reduced:
    - source: "精密、闪耀、辉光、复杂纹理、体积、广角、动态灯光等高风险词"
      action: "删除 / 降级为一个扁平小色块 / 改为固定固有色"
```

“受控、少量、极轻、避免”不能抵消多次重复的高风险词。若同一 prompt 同时反复要求高光、辉光、珠光、反射或精密结构，删除重复项，只保留一个最必要的视觉结果。

## 场景生成强化块

场景文生图与场景图生图必须写入最终提示词：

```text
必选真实图片输入：reference-01-core-scene.jpg（主导）+ reference-02-clear-line-scene.jpg。
图1职责：继承整体构图秩序、主次关系、高明度底面与成组细节的分配、主体优先、前中远层次及中长焦压缩空间；不复制具体人物、住宅、动物、时代或配色。
图2职责：继承清晰流畅闭合的数字勾线、外轮廓/内部结构线/远景线层级、平整无笔触色块；线条是空间骨架，即使移除光影，构图与物体关系仍成立。
空间：压缩纵深中的层叠空间；相机相对主要立面轻微离轴，以前景局部遮挡、桌面或结构边缘、人物与开口的平面错位形成前中远层次。避免正投影式陈列、单一立面构图、轴线锁死，也避免广角斜拍、强汇聚线和夸张近大远小。
色彩：保留连续的大面积高明度底面和浅色低细节区；深色与高饱和色集中于主体、关键道具和少数锚点；不同对象保持固有色，避免暗部连片和统一暖光覆盖全画面。
光线：环境光均匀、固有色优先、光影预烘焙；阴影是少量边界明确的辅助色块。局部灯光不形成大范围光池、体积光、空气辉光、动态反射或全局染色。
叙事：关系密度高而视觉噪声低，以主体行动、关键道具、线索和环境响应形成可读关系；细节成组，呼吸区完整，不用满墙小物、纹理、光点或背景人物表达叙事。
```

## 剧本与分镜质量检查

- 是否忠实保留用户或上游故事
- 主体是否有可见即时目标
- 触发、行动、变化和结束状态是否清楚
- 每镜是否有故事功能
- 相邻镜头是否不只是景别变化
- 道具是否有故事功能而非孤立陈列
- 装饰细节是否服务剧情
- 动作规模是否适合有限动画
- 关闭动画后关键帧是否仍然成立
- 删除装饰后故事是否仍能理解
- 是否按职责选择 assets，未复制其具体题材
